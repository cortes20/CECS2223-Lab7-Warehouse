# Warehouse Management System (C++)

This project is a C++ program that simulates a basic warehouse management system using object-oriented programming.

## Features
- Uses classes such as Warehouse, Circle, Cylinder, and Sphere
- Demonstrates data organization and management
- Implements input validation
- Applies modular programming concepts

## Technologies
- C++
- Object-Oriented Programming (OOP)

## Purpose
This project was developed as part of coursework to strengthen programming logic, problem-solving, and software development skills.
